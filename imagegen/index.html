ImageGen

本地 AI 生图客户端 / Local AI Image Generation Desktop Client

中文简介：ImageGen 是一款运行在用户本机的 AI 生图桌面客户端。用户可自行选择将历史对话与生图记录同步到本人 Google Drive 的应用专属目录（appDataFolder），以便在个人设备间迁移或备份数据。

Overview: ImageGen is a local AI image generation desktop client. Users can optionally sync their conversation and generation history to their own Google Drive application-specific folder (appDataFolder) for personal backup and cross-device sync.

核心特点 / Key Features

  • 本地运行界面与记录存储，生成配置由用户自主控制 / Runs locally with user-controlled model providers and local storage.
  • 可选 Google Drive 同步，仅使用 drive.appdata 权限访问应用专属隐藏目录 / Optional Google Drive sync using only the drive.appdata scope.
  • 随时可断开连接并撤销授权 / Disconnect and revoke access at any time.
